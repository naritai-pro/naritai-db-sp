# naritai-db-sp｜データベーススペシャリスト過去問演習

データベーススペシャリスト試験の過去問を、ブラウザで解いて復習できる学習アプリです。午前の選択問題から午後の記述・作図問題まで、自分のペースで取り組めます。

**[アプリを使う](https://ipa-db-sp.naritai.app/)**

個人学習や教材づくり、別の学習アプリへの応用など、幅広い用途で活用いただけます。ソースコードはMIT-0ライセンスで公開しています。適用範囲は[ライセンス](#ライセンス)を参照してください。

## できること

- **午前問題の演習：** 選択肢を選んで解答し、正答を確認できます。消去法での選択肢の除外や、解き直しにも対応しています。
- **午後問題の演習：** 問題文・表・図を参照しながら記述答案を入力できます。概念データモデルの関係を作図する設問にも対応しています。
- **解答の振り返り：** 自分の答案とIPAの解答例を比較し、解説を読んで復習できます。
- **途中から再開：** 答案や進捗をブラウザに保存します。
- **AIへの相談：** 問題と自分の答案などをコピーし、ChatGPTなどの相談先に貼り付けられます。
- **印刷用PDF：** 問題・解答用紙・公式解答例をPDF一覧から取得できます。

## 収録範囲

2016〜2025年度のデータベーススペシャリスト試験、計10回分を収録しています。2016〜2019年度は春期、2020年度は10月、2021〜2025年度は秋期の問題です。

| 区分 | 収録内容 |
| --- | --- |
| 午前Ⅰ・午前Ⅱ | 年度別の選択問題 |
| 午後Ⅰ | 30問（各年度3問） |
| 午後Ⅱ | 20問（各年度2問） |

過去問は出題当時の区分名で掲載しています。現在の試験制度・日程は[IPAの試験情報](https://www.ipa.go.jp/shiken/)をご確認ください。

## 使い方

1. 一覧から年度・区分・問題を選びます。
2. 選択肢を選ぶか、記述・作図の答案を入力します。
3. 解答例や解説を確認し、必要に応じて解き直します。

午後の記述答案は、IPAの解答例と比較して振り返るためのものです。独自の解説・予想配点は、IPAの公式解答例・採点講評とは区別して掲載しています。

### 学習記録について

- ログインは不要です。答案や進捗はサーバーに送信せず、利用中のブラウザの `localStorage` に保存します。
- 学習記録の保存期限は最終変更から6か月です。閲覧だけでは延長されません。
- 同じブラウザ・同じサイトで続きを再開できます。端末間の同期はありません。
- ブラウザのサイトデータを削除すると、学習記録も削除されます。
- AI相談用のコピーは、利用者が自分で相談先に貼り付ける機能です。

## ローカルで動かす

Node.js 24とnpmを使用します。

```sh
git clone https://github.com/naritai-pro/naritai-db-sp.git
cd naritai-db-sp
npm ci
npm run dev
```

[ローカルの開発画面](http://127.0.0.1:4173/)を開いてください。編集内容は開発サーバーに自動反映されます。

本番用ビルドを確認する場合は、次のコマンドを実行します。

```sh
npm run build
npm run check:deploy
npm run preview
```

プレビューは[こちら](http://localhost:4174/)で開けます。`check:deploy` はアップロードを行わない検証です。

HTML・CSS・TypeScriptとViteで構成したSPAを、Cloudflare Workers Static Assetsで配信しています。開発・配信の詳細は[開発ガイド](docs/development.md)、過去問の追加は[午後Ⅰ・午後Ⅱの演習仕様と過去問の追加手順](docs/afternoon-exercises.md)を参照してください。
