採点状況を見る

問1

グラフデータモデルの一つである，プロパティグラフに関する記述のうち，適切なものはどれか。

人をノード、所属先とのつながりをリレーションシップとすると、氏名は人の属性、着任日はつながりの属性として記録できる。このようにノードにもリレーションシップにもプロパティを付けられる。主語・述語・目的語の三つ組はRDFの表現である。

問2

概念データモデルの説明として，最も適切なものはどれか。

例えば販売業務なら、顧客・注文・商品という実体と、それらの間の関係を表す。「どんな情報があり、どう結び付くか」が概念データモデルの対象になる。業務を処理する順序や、どのサーバに表を配置するかは別の設計事項である。

問3

UMLを用いて表した商品と倉庫のデータモデルに関する記述のうち，適切なものはどれか。ここで，商品の倉庫間の移動はないものとする。

図の「在庫商品」から倉庫側の端を見ると、多重度は1。各在庫商品には倉庫が一つ決まる。同じ商品を二つの倉庫に初めて入れると、商品と格納先の組合せが二つできるので、在庫商品も2件増える。出庫側は0..＊なので、まだ出庫していない在庫商品も表せる。

問4

従業員の，従業員番号，氏名及び使用できるプログラム言語を管理するために，“従業員”表及び“プログラム言語”表を設計する。“プログラム言語を2種類以上使用できる従業員がいる。プログラム言語を全く使用できない従業員もいる。”という状況を管理する“プログラム言語”表の設計として，適切なものはどれか。ここで，実線の下線は主キーを表す。

〔従業員表〕
従業員（従業員番号，氏名）

従業員番号と言語の組を主キーにする。例えば（101, Java）と（101, SQL）は別の行になり、さらに（102, SQL）も登録できる。片方の列だけを主キーにすると、どちらかの登録が妨げられる。使える言語がない従業員は従業員表にだけ登録すればよい。

問5

関数従属に関する記述のうち，適切なものはどれか。ここで，A，B，Cはある関係の属性の集合とする。

Aが等しい任意の2行でBとCの組全体が一致するなら、そのうちBだけを見ても、Cだけを見ても値は一致する。したがって A → B∪C から A → B と A → C を導ける。これは関数従属性の分解則である。

問7

SQLの3値論理において，a，bに入る字句の組合せはどれか。

“真 AND 不定”は［ a ］であり，“偽 AND 不定”は［ b ］である。

ANDは両方が真のときだけ真になる。真と不定を組み合わせると、もう片方が真か偽かで結果が変わるため不定のまま。一方が偽なら、もう片方がどちらでも結果は偽。したがって a は不定、b は偽になる。

問8

表定義に基づいて作成された“システム担当者”表において，トランザクションAの複合文内のSQL文全てを正常終了させるためにaに入れる字句はどれか。ここで，実線の下線は主キーを表す。

〔表定義〕

CREATE TABLE システム担当者 (
    システム番号 INTEGER,
    担当者番号 INTEGER NOT NULL,
    CONSTRAINT PK_システム番号 PRIMARY KEY(システム番号),
    CONSTRAINT UK_担当者番号 UNIQUE(担当者番号)
        DEFERRABLE INITIALLY IMMEDIATE
)
システム担当者
システム番号担当者番号
1234111
6789222

〔トランザクションAの複合文内のSQL文〕

SET CONSTRAINTS ［ a ］;
UPDATE システム担当者 SET 担当者番号 = 222 WHERE システム番号 = 1234;
UPDATE システム担当者 SET 担当者番号 = 111 WHERE システム番号 = 6789;
COMMIT;

担当者番号を交換すると、最初のUPDATE直後だけは2行とも222になる。2回目のUPDATE後には222と111に分かれる。そこで遅延可能と定義された担当者番号の一意制約にDEFERREDを指定し、コミット時に検査する。システム番号の値は一度も変わらない。

問9

“名簿1”表と“名簿2”表のそれぞれ対応する行が全て等しいかどうかを確認するSQL文のa，b，cに入れる適切な字句はどれか。

名簿1
名前住所性別年齢
試験 太郎東京男22
情報 花子大阪女24
処理 一郎京都男35
名簿2
名前住所性別年齢
試験 太郎東京男22
情報 花子大阪女24
処理 一郎京都男35

〔SQL文〕

SELECT CASE WHEN COUNT(*) = 0 THEN '等しい' ELSE '異なる' END AS 結果
  FROM ((SELECT * FROM 名簿1 ［ a ］ SELECT * FROM 名簿2)
         ［ b ］
        (SELECT * FROM 名簿1 ［ c ］ SELECT * FROM 名簿2)
       ) COMPARE

二つの名簿のどちらかにある行をUNIONで集め、両方にある行をINTERSECTで求める。前者から後者をEXCEPTで引くと、片方にしかない行だけが残る。その件数が0なら行の集合は等しい。この比較では、重複する同一行の個数までは区別しない。

問10

関係演算において，商演算と同等な結果が得られる演算の組合せはどれか。

商は「要求された全種類を満たすもの」を求める演算。例えば候補者を履修表から射影し、候補者と必修科目の直積を作る。そこから実際の履修を引けば不足した組が残る。不足のある候補者を射影して全候補者から引くと、全科目を履修した人だけが残る。使った演算は直積・射影・差である。

問11

図のような関係データベースの“注文”表と“注文明細”表がある。“注文”表の行を削除すると，対応する“注文明細”表の行が，自動的に削除されるようにしたい。参照制約定義の削除規則（ON DELETE）に指定する語句はどれか。ここで，図中の実線の下線は主キーを，破線の下線は外部キーを表す。

注文

注文番号注文日顧客番号

注文明細

注文番号明細番号商品番号数量

注文明細の注文番号は、親である注文の行を参照する。外部キーにON DELETE CASCADEを指定すると、親の削除がその親を参照する明細に伝わる。RESTRICTを指定すると、参照する明細がある間は親の削除が拒否される。

問12

DBMSをシステム障害発生後に再立上げするとき，ロールフォワードすべきトランザクションとロールバックすべきトランザクションの組合せとして，適切なものはどれか。ここで，トランザクションの中で実行される処理内容は次のとおりとする。

処理内容
トランザクションデータベースに対するRead回数とWrite回数
T1，T2Read 10，Write 20
T3，T4Read 100
T5，T6Read 20，Write 10

線の右端の黒丸（●）はコミット済み，黒丸のない線は未コミットを示す。

図の黒丸はコミットを表す。更新のあるT2とT5はチェックポイント後にコミットしているので更新を再適用する。更新のあるT6は障害時に未コミットなので取り消す。T1はチェックポイント前にコミット済み。T3とT4は図の線が障害時点まで続いていても、表を見ると読取りだけなので、取り消す更新がない。

問13

RDBMSのクラスタ化インデックスに関する記述のうち，適切なものはどれか。

クラスタ化インデックスは、対象列のキー順にレコードを配置する。同じ範囲のキーを読むとき、近いブロックからまとめて読みやすくなる。一つの表のレコード配置に採用できる順序は一つだが、別の検索キーに対する非クラスタ化インデックスは併設できる。

問14

データベースのREDOのべき等（idempotent）の説明として，適切なものはどれか。

同じ更新のREDOを繰り返しても、最後のデータが1回適用した場合と一致する性質をべき等という。例えば残高を更新後の120に戻すなら、2回目も120になる。差額20を毎回足すだけでは、再実行で140になってしまう。

問15

トランザクションT1，T2を同時実行した際に，次の異状を防ぐことができるトランザクションの隔離性水準のうち，最も水準の低いものはどれか。

〔異状〕
T1が同じデータを複数回読み込んでいる途中で，T2がそのデータを更新してコミットしたことによって，T1が更新していないにもかかわらずT1が読み込むデータが変わってしまう。

T1が同じ行を読み直したとき、途中でコミットしたT2の更新によって値が変わるのは反復不能読取りである。READ COMMITTEDでは各読取りの時点でコミット済みの値を読めるため、この現象が起こり得る。選択肢の中でこれを防ぐ最も低い水準はREPEATABLE READである。

問16

二つのトランザクションT1とT2を並列に実行した結果が，T1の完了後にT2を実行した結果，又はT2の完了後にT1を実行した結果と等しい場合，このトランザクションスケジュールの性質を何と呼ぶか。

T1とT2の処理が入り交じっていても、T1→T2またはT2→T1のどちらかで順番に処理した場合と同等なら、そのスケジュールは直列化可能である。原子性は、一つのトランザクションの変更が全部反映されるか全部取り消されるかという性質である。

問17

DBMSにおいて，トランザクション間でデッドロックが発生していることを検出するために使用するものはどれか。

待ちグラフで、待つ側から資源を保持する側へ矢印を引く。T1がT2を待ち、T2がT1を待つと矢印が一周し、互いに先へ進めない。この循環を探すことでデッドロックを検出する。2相ロックを使っていても相互待ちは起こり得る。

問18

ブロックチェーンのデータ構造の特徴として，適切なものはどれか。

各ブロックは前のブロックの内容に対応するハッシュ値を含む。過去の内容を書き換えると計算し直したハッシュ値が後続ブロックの参照値と一致しなくなる。この連鎖に着目してエを選ぶ。ハッシュで確認できるのは履歴の整合性であり、記録した取引内容そのものの真偽とは区別する。

問19

暗号化処理時における暗号化装置の消費電力を測定するなどして，当該装置内部の秘密情報を推定する攻撃はどれか。

暗号装置の消費電力や処理時間など、処理に伴って外部から観測できる情報を手掛かりにするのがサイドチャネル攻撃である。設問では「消費電力」が判断の根拠になる。キーロガーが記録するのはキー入力である。

問20

メッセージにRSA方式のディジタル署名を付与して2者間で送受信する。そのときに使用するディジタル署名の検証鍵とその使用方法はどれか。

送信者は自分の秘密鍵で署名を作り、受信者はそれと対になる送信者の公開鍵で署名を検証する。受信者は受け取った本文からもダイジェストを計算し、署名がその本文に対応するかを確認する。エが説明しているのは署名を作る側の操作である。

問21

秘密鍵が漏えいした場合であっても，過去に通信した暗号文を復号することができないという暗号技術の性質はどれか。

前方秘匿性があれば、長期の秘密鍵が後で漏れても、以前に記録された通信の暗号文をその鍵から復号できない。例えば通信ごとに一時的な鍵交換を行い、使い終わった秘密を消すことで、過去のセッション鍵を長期鍵から再現できないようにする。

問22

容量がa Mバイトでアクセス時間がxナノ秒の命令キャッシュと，容量がb Mバイトでアクセス時間がyナノ秒の主記憶をもつシステムにおいて，CPUからみた，主記憶と命令キャッシュとを合わせた平均アクセス時間を表す式はどれか。ここで，読み込みたい命令コードが命令キャッシュに存在しない確率をrとし，キャッシュ管理に関するオーバヘッドは無視できるものとする。

rは命令がキャッシュに「存在しない」確率。したがってヒットは1−rで時間はx、ミスはrで時間はyとなり、設問の前提での加重平均は (1−r)×x＋r×y。r＝0なら答えがx、r＝1ならyになることでも確かめられる。容量a・bで重み付けする必要はない。

問23

4台の磁気ディスクから構成されたRAID6のディスクアレイシステムがあり，パリティの計算方法は次のとおりである。磁気ディスク2と磁気ディスク3が故障したとき，データブロックA₁，A₂を復元するのに必要なデータブロックの組合せとして適切なものはどれか。ここで，パリティの計算方法では，“データブロックX”の内容を“X”で示し，⊕は排他的論理和を示す。

ディスクアレイシステム（各列はデータブロック）
磁気ディスク1磁気ディスク2磁気ディスク3磁気ディスク4
AₚA₁A₂Aᵥ
B₁BₚB₂Bᵥ
CₚC₁C₂Cᵥ
D₁DₚD₂Dᵥ

〔パリティの計算方法〕

Aᵥ＝D₁⊕A₂Bᵥ＝A₁⊕B₂Cᵥ＝B₁⊕C₂Dᵥ＝C₁⊕D₂Aₚ＝A₁⊕A₂Bₚ＝B₁⊕B₂Cₚ＝C₁⊕C₂Dₚ＝D₁⊕D₂

故障後もディスク1のD₁・Aₚとディスク4のAᵥを読める。図の Aᵥ＝D₁⊕A₂ の両辺にD₁をXORすると A₂＝Aᵥ⊕D₁。次に Aₚ＝A₁⊕A₂ から A₁＝Aₚ⊕A₂ と求まる。同じ値を2回XORすると打ち消し合うので、まずA₂を復元し、それを使ってA₁も復元できる。

問24

オブジェクト指向における抽象クラスで，できないことはどれか。

設問が聞いているのは「できないこと」。抽象クラスには共通の属性や振る舞いを定義でき、継承関係も持てるが、そのクラス自体のインスタンスを直接生成することはできない。例えば抽象クラス「図形」を継承した具象クラス「円」なら、その円のインスタンスを作れる。

問25

エクストリームプログラミング（XP）のプラクティスとして，適切なものはどれか。

単体テストを通った変更を早く全体に取り込み、組み合わせても動作するかを確かめるのは、XPの継続的インテグレーションに合う。変更を小さく頻繁に結合するほど、不整合の原因となった変更を絞りやすい。ほかにペアプログラミングやコードの共同所有もXPのプラクティスである。
