# 午後Ⅰ・午後Ⅱの演習仕様と過去問の追加手順

2025年度秋期の午後Ⅰ問1〜3を基準に、別年度の大問を同じ形式で収録するための仕様。2021〜2025年度の午後Ⅰ・午後Ⅱをサイドバーで選べる。午後Ⅰ全15問、午後Ⅱ全10問に問題資料・解答用紙・解説がある。

## 問題を選んで解く

- サイドバーは「午後Ⅰ／午後Ⅱ → 問番号 → 年度」の順に展開する。同じ問番号で年度を比較できる。午後Ⅰは問1〜3、午後Ⅱは問1〜2。収録済みは「演習」、未収録は「冊子」と表示する。
- 大問IDは年度・期・試験・区分・問番号の組合せ。例は `2025-autumn-db-pm1-q1`。一覧は `/`、解答用紙は `/2025/pm1/q1`、解説は `/2025/pm1/q1/answer`。未収録の大問のURLを開くと冊子案内を表示する。旧ハッシュURLは同じ大問の新URLへ変換する。
- 上部には一覧・年度・区分・問番号・題名をパンくずで1行に表示し、保存状態を右端に置く。PCでは左に解答用紙、右に問題資料。幅900px以下では資料を先に置く縦並びにする。
- PCでスクロールしても左右の見出しは上端が揃い、上枠・角丸と上の余白が見える。解答用紙の見出し右には「解答する」「解説を見る」「解答例原本」をこの順に置く。問題資料の見出しには問題冊子の原本リンクを置く。

## 問題資料と解答欄

本文・注記・設問は冊子の順序と用語を保ち、スクロールできるHTMLで表示する。原本の行末は再現しなくてよい。設問文は資料と解答用紙の両方に載せる。解答欄では同じ問いの言い換えを重ねず、複数の空欄には原本の記号を付ける。

資料の概念データモデルは白地のSVGで、余白、細い線、角の四角い箱、下側の図名を使う。長い箱名は意味の区切りで2行にし、図全体をパネル幅に収める。スキーマ・表・SQLも、選択・コピーできる文字として再構成する。設問中の「図2」「表1」などをクリックすると、問題資料が対応する図表までスクロールする。

| 原本が求める答案 | 解答用紙での操作 |
| --- | --- |
| 属性名・数値・SQLの空欄 | 短い記入欄。連続する空欄は小問ごとに横並びにし、幅に応じて折り返す。 |
| 選択式 | 正規形や処理番号は、原本にある候補だけをプルダウンに並べる。 |
| 字数指定の理由・根拠 | 入力は改行不可、表示は自動折り返し。貼り付け時も改行を取り除く。高さは上限41字ごとに1行分とし、25字・30字は1行、70字は2行。枠の下に余白を設けて文字数を表示し、超過は警告する。41字は高さの目安で、実際の折り返し位置は幅による。 |
| 関係スキーマ | 属性名を選択して主キーの実線・外部キーの破線を付け外しする。ボタンの文字にも対応する下線を付ける。連続する空欄は複数列に並べ、ボタンをグループの上下で共用する。選択中は A が主キー、S が外部キー。選択がないとボタンは無効になり、文字キーは通常入力になる。 |
| 概念データモデルの補完 | 緑の解答用キャンバスをパネル幅いっぱいに表示する。始点の箱から終点の箱へドラッグして追加し、追加した緑の線をクリックして削除する。左上のタブまたは数字キーで 1＝1対1、2＝1対多、対応する図のみ 3＝サブタイプ。操作説明はタブの横、SVGの凡例は図の下に置く。 |

1対多は「1」から「多」へ矢印を向ける。サブタイプはスーパータイプからサブタイプへ結び、分類の記号は△。問題で与えられた線と学習者が追加した線は別々に保持する。

## 保存・解説・コピー

ViteとバニラTypeScriptのSPAを構築し、Cloudflare Workers Static Assetsから `dist/` を配信する。表示、編集、保存、コピーはブラウザ内で行う。

- 入力・作図の変更時に、`localStorage` の `dbsp:v1:<大問ID>` へ保存する。`fields` は欄IDごとの文字列、`edges` は設問番号ごとの追加線、`ratings` は設問ごとの自己評価、`updated` は最終更新時刻。キーの下線は `PK[属性]`、`FK[属性]`、両方なら `PK+FK[属性]` で保持する。
- 再読み込み時に答案を復元する。最終変更から暦で6か月後を期限とし、その日がない月は月末とする。期限を過ぎた記録は読込み時に削除する。保存に失敗した場合は画面で知らせ、表示中の答案をコピーできる。
- 解説では、小問ごとにIPA解答例と解き方を読める。「自分の答案を表示」をオンにすると、自分の答案と見比べられる。
- 解き方はです・ます調で、何を整理するか、本文や図表のどこを読むか、その条件からどう答えを導くかを説明する。判断に使う語句を太字にする。根拠が複数箇所にあるときは、それぞれに本文リンクを付ける。本文では根拠に蛍光ペンを引き、選択中の箇所は別の色で示す。図表内の特定箇所を指すときは、例えば `図3{③}`、複数なら `図2{②|③}` と記す。画面のリンクには図表番号だけが表示され、クリックすると指定した手順・行・エンティティなどを強調する。
- ChatGPT用コピーは大問全体または設問単位。設問指定でも問題本文・図表は全体を含め、答案と解答例を対象設問に絞る。解答画面は問題と自分の答案、解説画面はIPA解答例とその出典も含める。関係線は始点・終点・関係種別を持つJSON、下線は上記のキー表記で渡す。未記入は「未解答」。クリップボードが使えない場合は手動コピー用のテキスト欄を表示する。

## 別年度の大問を追加する手順

1. 対象年度のIPA問題冊子と解答例を突き合わせる。大問の開始ページ、全設問・空欄、図表番号、字数、キーの下線、図の既存線と補う線を確認する。問題と解答例の原本リンクはそれぞれ該当ページを指定する。
2. [QuestionとDiagramの型](../src/exam.ts)に沿って大問データを作る。作図・スキーマには[問1](../src/university.ts)、SQL・字数指定・選択式には[問3](../src/inventory.ts)が参考になる。[問2](../src/question.json)には専用の描画・入力処理がある。
3. 以下の対応でデータを入力し、画面とコピーの両方で同じ内容を参照できるようにする。

   | 項目 | 登録内容 |
   | --- | --- |
   | `id, title, source, paper, solution` | 大問ID、題名、年度・期・試験名・区分・問番号、問題冊子URL、解答例URL。 |
   | `booklet, figures, schema` | 本文を順番に並べる。`@1` は `figures[0]` の挿入位置。図表の `caption` は「図1　…」「表1　…」のように番号と題名を全角空白で区切る。図番号と配列上の番号は別物。たとえば問3の「表1」は `@5`。 |
   | `materialBlocks` | 過去問の問題資料。本文・図表名は `text`、アンカーは `reference`。スキーマ・SQLは `lines`、表は `table.headers / rows`、注記は `notes`。設問で参照する下線部は本文または表のセル内の該当部分を `underline` に指定する。概念図は `diagramIndex` で与件の箱と線だけを描く。その他の模式図は手描きSVGの `illustration` と構造を説明する `description` を用意する。文字の輪郭を画像からトレースしない。 |
   | `sections` | 設問順に `heading`（原文）、`title`（コピー用見出し）、`prompts`（小問の原文）、`fields`、`note`（独自解説）を置く。`prompts.before` は対象の欄IDか `diagram`。各欄は `[欄ID, 表示ラベル, IPA解答例]`。公開後は欄IDと設問順が保存済み答案に対応する。 |
   | `explanations` | 各項目に `section`（1から数えた設問番号）、`before`（表示する解答欄・図の位置）、`title`、`text`、`quotes` を記す。`text` の `**語句**` は太字、図表番号は資料へのリンクになる。`quotes` には掲載本文の該当箇所をそのまま入れる。 |
   | `controls` | 欄IDごとに `short`（短文）、`step`（①〜④）、`step5`（①〜⑤）、`normal`（正規形）、選択肢の文字列配列、`schema`（下線付き）、または正の数値（上限字数）を指定する。通常の自由記述は省略できる。 |
   | `diagrams` | 対象設問の番号（1始まり）、図名、課題文、`nodes`（箱名・中心座標）、`fixed`（既存線）、`answer`（解答例の追加線）。線は `[始点の箱名, 終点の箱名, 種別]`。必要に応じて `viewBox`、折れ線の `routes`、2行表示の `labelLines` を指定する。原本の折れ線を再現する `fixedPath`・`solutionPath` と箱ごとの `nodeSizes` も指定できる。線の意味は必ず `fixed`・`answer` に併記する。 |

4. [main.ts](../src/main.ts) の `exercises` にID・題名・読み込み関数を登録する。2021〜2024年度の午後Ⅰ、および全年度の午後Ⅱは `src/archive/` の大問JSONと `src/archive-titles.json` のID・題名から読み込む。この登録から一覧とサイドバーの「演習」リンクが作られる。[library.ts](../src/library.ts) には2021〜2025年度の枠が既にある。
5. **別年度で最初に確認する箇所**は一覧カードとパンくず。年度は問題IDから表示する。追加した大問の和暦と問番号が原本に一致することを確認する。
6. [入力欄](../src/answer-field.ts)と解説画面には問2の欄IDに依存する処理がある（例：`1-2a` は正規形、`2-` で始まる欄はスキーマ）。新しい欄IDには大問固有の接頭辞を使い、形式は `controls` で指定する。
7. [問題資料とコピー用本文](../src/booklet.ts)の描画を確認する。現状、`figures` のない問題は問2用の図・帳票に分岐し、汎用側でも空の `lines` は最初の概念図、先頭が「表1」の題名は問3のSQL表として扱う。新年度の表や複数の概念図がこの条件に合わなければ、表示とテキスト化の両方を拡張する。[作図](../src/diagram.ts)も同じ設問に複数の図があるときは `prompts.before` に `diagram:0` のように大問内の図インデックスを指定する。資料専用の図は `section: 0`。同じ箱を結ぶ線は `selfRelations`、同じ2箱の間の複数の関係は `allowParallel`、箱名の解答欄は `nodeFields` で指定する。原本が別の表現を要求する場合はその設問に合わせて対応する。

## 追加後の確認

- `npm run check:archive` で図表リンク・表の列数・線の端点を検証し、`npm run build` を通す。その後、`npm run preview` で一覧・サイドバー・直接URLから対象年度の同じ大問に入れることを確認する。
- 問題資料と解答欄を原本と照合する。全小問に入力でき、図表リンクが正しい位置へ移動し、狭い画面でも概念図の端が欠けないことを確認する。
- 実際に文字・下線・線を入力し、再読み込みと大問切り替えを行う。解説で自分の答案と解答例が区別でき、他年度の同じ問番号に記録が混ざらないことを確認する。
- 大問全体と設問単位でコピーし、出典、図の向き、キーの区別、未解答の扱いを確認する。解答画面からのコピーに模範解答が含まれていないことも確認する。
