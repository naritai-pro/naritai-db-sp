# naritai-db-sp｜データベーススペシャリスト過去問演習

2027年のデータベーススペシャリスト試験合格に向けて、ブラウザで過去問を解き、自分の答案を見直すための学習アプリ。

2016〜2025年度の午後Ⅰ（30問）・午後Ⅱ（20問）は、同じ演習画面で解ける。問題資料は選択できる本文・表・SVGからなり、空欄ごとに答案を入力できる。概念データモデルは箱を結んで作図する。解説画面では自分の答案とIPA解答例を比較し、解き方から本文の根拠に戻れる。

別年度の過去問を追加するときは、[午後Ⅰ・午後Ⅱの演習仕様と過去問の追加手順](docs/afternoon-exercises.md)を参照。

## 起動方法

Node.js 24で `npm ci`、`npm run dev` を順に実行し、[開発画面](http://127.0.0.1:4173/)を開く。サーバーを起動したまま編集すると、CSS・TypeScript・問題データの変更がHMRで反映される。HTMLの変更時はブラウザが自動で再読み込みする。本番用の確認は `npm run build` の後に `npm run preview`。Cloudflare Workers Static Assets の配信先は `wrangler.jsonc` で `dist/` に設定している。

一覧から問2を開き、図1または図4の始点の箱から終点の箱までドラッグする。追加した緑の線はクリックで削除できる。同じURLを再読み込みすると、矢印と記述答案を復元する。「解説を見る」で答案を見比べ、ページ末尾で大問全体または設問を選んで「問題・答案・解答例をコピー」を押す。

## 対象とする試験・過去問

2016〜2019年度は春期、2020年度は10月、2021〜2025年度は秋期の計10回分を扱う。各年度の午後Ⅰ・午後Ⅱについて、選択問題も含め、どの大問でも練習できるようにする。午前Ⅰ・午前Ⅱは2016〜2025年度のDB実施回を年度別に収録する。左の一覧で年度を選び、記号を押すと解答が確定する。選択肢の文章では消去法の除外・解除ができる。問題一覧の「リセット」でその年度・区分だけを解き直せる。

目標とする令和8年度後期のDB試験はCBT方式。過去問は冊子の「午後Ⅰ」「午後Ⅱ」という表記で探せるようにし、現在の科目名も併記する。

| 過去問の区分 | 現在の科目 | 2027年の実施期間 |
| --- | --- | --- |
| 午前Ⅰ・午前Ⅱ | 科目A-1・A-2 | 2月20日〜3月2日 |
| 午後Ⅰ・午後Ⅱ | 科目B-1・B-2 | 3月16日〜3月28日 |

申込受付は2027年1月27日〜2月27日。[IPAの後期試験日程](https://www.ipa.go.jp/shiken/mousikomi/moushikomi.html)を参照。

## 演習の流れ

1. **問題を選ぶ。** 年度・区分・大問を選ぶ。一覧から「解答中」の続きを開いたり、「要復習」の問題を選んで解き直したりできる。
2. **解答画面で解く。** 長い事例文、ER図、表を参照しながら、小問ごとに答案を入力する。PCでは左に解答欄、右に広めの問題資料を置く。問2の資料はIPAの問題冊子12〜17ページに沿って、本文と図表を連続してスクロールできる形で表示する。入力は自動保存し、途中で閉じても続きから再開できる。解答例はこの画面に表示しない。
3. **解説画面で振り返る。** 小問ごとに自分の答案とIPAの解答例を並べる。独自解説では「本文のどの条件から、その答えが導けるか」を示す。記述式には同じ意味の別表現があるので、文字列の一致で採点せず、「解けた」「要復習」を自分で記録する。

## フロントエンドの構成

初版は静的配信するSPAとする。Wrangler の `assets.directory` に `./dist` を指定し、Worker スクリプトのエントリーポイント（`main`）は設けない。たとえば `/2025/pm1/q1` を直接開くと、Cloudflare はトップページを配信し、ブラウザがパスを読んで該当する大問のデータを読み込む。画面の描画・答案の復元・保存期限の判定はすべてブラウザで行う。

Vite の `vanilla-ts` テンプレートを使い、HTML・CSS・TypeScript で実装する。開発中は Vite の開発サーバーを使い、本番用には `tsc --noEmit && vite build` で型検査とビルドを実行する。生成された `dist/` を Workers Static Assets の配信ディレクトリに指定する。[Vite の TypeScript ガイド](https://vite.dev/guide/features.html#typescript)

問題一覧・解答・解説は画面ごとに TypeScript モジュールを分ける。年度・区分・問番号をURLのパスにし、解説には `/answer` を付ける。これにより、通常のリンクとブラウザの「戻る」で移動でき、再読み込みでも同じ大問が開く。解答画面では入力欄を維持したまま答案を保存し、日本語変換やカーソル位置を保つ。

大問ごとに問題文・図表・設問・解説をJSONまたはTypeScriptモジュールにまとめ、選んだ大問だけを読み込む。答案の保存・復元と6か月の期限判定は共通モジュールにまとめ、将来の午前問題でも使う。

## 図を解答する設問

概念データモデルは問題データからSVGで描画する。始点の箱から終点の箱へドラッグして関係を追加し、追加した緑の線をクリックして削除する。問題で与えられた線、受験者が追加した線、IPA解答例の線を区別し、学習記録には受験者が追加した線を保存する。

## ChatGPTに相談するためのコピー

選択中の小問について、年度・問番号・出典、設問文、解答に必要な事例本文と図表、図の凡例、自分の答案を見出し付きの Markdown にまとめる。図は日本語の表示名を含む構造化 JSON、表は列名を含むテキストとして埋め込む。未解答欄も明示する。解答画面では「問題と自分の答案をコピー」、解説画面では「公式解答例も含めてコピー」を選べるようにする。ボタンを押すとブラウザでテキストを組み立ててクリップボードに書き込み、利用者が相談先に貼り付ける。

## 配信と学習記録

HTML・CSS・JavaScript、問題データ（JSON）、図表は [Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) で配信する。答案や進捗はサーバーに送らず、初版はログインもサーバー側のデータベースも使わない。

- **保存の単位：** 年度・区分・大問から一意なID（例：`2025-autumn-db-pm1-q1`）を決め、設問別の答案と最終更新日時をブラウザの `localStorage` に保存する。
- **期限：** 問題ごとに、答案を最後に変更してから6か月。同じ日付がない月は月末を期限とする。閲覧だけでは延長しない。`localStorage` に自動失効機能はないため、起動時と記録の読み込み時に期限を確認し、期限を過ぎた記録を削除する。
- **再開の条件：** 同じブラウザ・同じサイトで再開できる。端末間の同期はなく、ブラウザのサイトデータを消すと記録も消える。保存できなかった場合は解答画面で知らせる。

## 実装の順序

1. **午後Ⅰの大問を1問だけ通して作る。** 公式の問題冊子を参照しながら入力できる形から始める。ブラウザを閉じて再開し、図表を確認し、解答例と比較して「要復習」にした問題を一覧から再度開ければ、学習に使い始められる。
2. **午後Ⅱを1問追加してから5年分に広げる。** 長い事例と複数の図表でも同じ画面で解けることを確かめ、以降は問題データの追加を中心に進める。
3. **午前Ⅰ・午前Ⅱを追加する。** 択一用の選択肢と正答判定を加え、年度別一覧と復習の仕組みは共用する。

教材は[IPAの過去問題・解答例・採点講評](https://www.ipa.go.jp/shiken/mondai-kaiotu/)を基にする。[過去問題の使用に関するIPAの案内](https://www.ipa.go.jp/shiken/faq.html)に沿って、各問に年度・期・試験名・区分・問番号と原本へのリンクを載せる。問題を改変した場合は明記し、IPAの解答例・採点講評と、このアプリで作成した解説を区別する。
